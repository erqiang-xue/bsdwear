# 虚拟试穿网页工具 — 设计规格

日期：2026-10-17  
状态：待用户审阅

## 1. 目标

做一个独立网页小工具：用户用摄像头实时预览自己，上传上装图片，点击试穿后看到尽量真实的 AI 换装效果。

明确不做：

- 不反编译或复制 Chrome 扩展 Anywear
- 第一版不做 Chrome 扩展、不做下装/裙装/连体
- 第一版不做自动连续抽帧视频流（准实时：手动点「试穿」）

## 2. 用户流程

1. 打开网页，授权摄像头，左侧显示实时预览。
2. 上传一张上装商品图（T 恤 / 衬衫 / 外套），右侧显示缩略图。
3. 摆好姿势后点击「试穿」：前端截取当前预览帧。
4. 前端将人体帧 + 上装图发到后端 `POST /api/try-on`。
5. 后端调用外部虚拟试穿 API，返回结果图。
6. 结果叠在预览区（或替换为结果图）；可下载；可再次试穿刷新。

## 3. 架构

```
浏览器 (Vite + React + TS)
  ├─ 摄像头预览 / 结果叠层
  ├─ 上装上传与压缩
  └─ 试穿按钮 → POST /api/try-on
         ↓
轻量后端 (Node + Express，同仓库)
  ├─ 校验与转发
  └─ 外部换装 API（Key 仅在服务端 .env）
```

密钥不进入浏览器。前端只拿结果图。

## 4. 界面

- 布局：左大预览，右操作栏。
- 操作栏：开启/关闭摄像头、上传上装、试穿、下载结果。
- 试穿中：加载态，禁用重复提交。
- 失败：可读中文错误（无摄像头权限、未选衣服、超时、API 余额/密钥问题等）。

## 5. API

### `POST /api/try-on`

- 入参：`person`（人体图，multipart 或 base64）、`garment`（上装图）。
- 出参：`{ image: string }`（结果图 URL 或 base64）。
- 超时：约 30 秒。
- 第一版只接一家供应商；通过环境变量配置（如 `TRYON_API_KEY`、`TRYON_API_URL`），便于更换。

供应商候选（实现时选一家可用、文档清晰的公开虚拟试穿 API，例如 Fashn 或同类）：须支持「人像 + 服装图 → 试穿结果」。

## 6. 技术选型

| 层 | 选型 |
|----|------|
| 前端 | Vite + React + TypeScript |
| 后端 | Node.js + Express（同 monorepo） |
| 图片 | 前端压缩后再传，限制分辨率与体积 |
| 配置 | `.env` / `.env.example`，不提交真实 Key |
| 运行 | 本地 `npm run dev` 可同时起前后端 |

## 7. 错误与边界

- 摄像头拒绝 / 无设备 → 提示并允许改用上传人像照片作为降级（可选；若工期紧可第二版再加）。
- 未上传上装就点试穿 → 前端拦截。
- API 超时、4xx/5xx、额度不足 → 后端映射为明确错误信息返回前端。
- 图片过大 → 前端压缩到约定上限（例如最长边 ≤ 1280、JPEG 质量可调）。

## 8. 成功标准（第一版）

- 本地打开网页，摄像头预览正常。
- 上传上装并试穿后，能看到明显换装结果（真实感取决于所选 API）。
- API Key 未配置或无效时，有清晰提示而非白屏。
- 有一份 README：如何配置 Key、如何启动。
